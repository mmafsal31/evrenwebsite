## 🆘 TROUBLESHOOTING

### Problem: Website doesn't load

**Solution 1 - Collect static files:**
```bash
python manage.py collectstatic --noinput
# Then reload
```

**Solution 2 - Check for errors:**
```bash
tail -20 /var/log/yourusername.pythonanywhere.com.error.log
```

### Problem: Styling looks broken (colors, fonts missing)

**Solution:**
```bash
# Clear and re-collect
rm -rf /home/yourusername/evrenwebsite/static/
python manage.py collectstatic --noinput
# Reload web app
```

### Problem: Menu doesn't appear or buttons don't work

**Solution:**
```bash
# Verify files were pulled
ls -la /home/yourusername/evrenwebsite/static/css/

# Should show:
# - mobile-optimized.css ← NEW FILE
# - responsive.css ← UPDATED
# - style.css ← UPDATED
```

### Problem: Changes from your computer not showing

**Solution:**
```bash
# Make sure you pushed
git push origin main

# On PythonAnywhere
git pull origin main

# Reload
# Dashboard → Web → Click Reload
```

### Problem: Database errors

**Solution:**
```bash
python manage.py migrate
python manage.py check
```
