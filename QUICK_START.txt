🚀 5-MINUTE SETUP:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. OPEN COMMAND PROMPT AND RUN:

   cd "c:\Users\dell\Desktop\evern website"
   
   python -m venv venv
   venv\Scripts\activate
   
   pip install -r requirements.txt

2. GENERATE PROJECT STRUCTURE:

   python COMPLETE_BUILD.py
   
   (This creates all models, views, URLs, and admin configuration)

3. CREATE DATABASE:

   python manage.py makemigrations
   python manage.py migrate

4. CREATE ADMIN ACCOUNT:

   python manage.py createsuperuser

5. GENERATE TEMPLATES:

   python BUILD_TEMPLATES.py
   
   (This creates all HTML templates and static files)

6. RUN THE SERVER:

   python manage.py runserver

7. OPEN IN BROWSER:

   Frontend:  http://localhost:8000
   Admin:     http://localhost:8000/admin

Issue: Port 8000 already in use
Fix: python manage.py runserver 8001

Issue: "No module named 'django'"
Fix: Activate virtual environment
     venv\Scripts\activate

Issue: Static files not loading
Fix: python manage.py collectstatic --noinput

Issue: Database errors
Fix: python manage.py migrate --fake-initial

Issue: Can't login to admin
Fix: Create new superuser
     python manage.py createsuperuser

🚀 DEPLOYMENT (PRODUCTION):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Update .env file with production settings
2. Change DEBUG=False in settings.py
3. Generate SECRET_KEY
4. Set ALLOWED_HOSTS
5. Configure PostgreSQL database
6. Collect static files: python manage.py collectstatic
7. Set up Gunicorn: pip install gunicorn
8. Configure Nginx
9. Use supervisor or systemd for process management
10. Set up SSL certificate with Let's Encrypt

See SETUP_GUIDE.md for detailed deployment instructions.
