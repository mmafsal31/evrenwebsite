🚀 STEP-BY-STEP INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

IMPORTANT: Follow these steps EXACTLY in order.

STEP 1: OPEN COMMAND PROMPT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Press Windows Key + R, type "cmd" and press Enter.

Navigate to project directory:

   cd "c:\Users\dell\Desktop\evern website"

Verify you're in the right directory:

   dir

You should see files like:
   • requirements.txt
   • README.md
   • COMPLETE_BUILD.py
   • BUILD_TEMPLATES.py
   • etc.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: CHECK PYTHON INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python --version

You should see: Python 3.13.x or higher

If not, download Python from: https://www.python.org/downloads/

IMPORTANT: During Python installation, check "Add Python to PATH"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3: CREATE VIRTUAL ENVIRONMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python -m venv venv

Wait for it to complete (may take 1-2 minutes).

You should now see a new "venv" folder in your directory.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4: ACTIVATE VIRTUAL ENVIRONMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   venv\Scripts\activate

The command prompt should now show: (venv) at the beginning of the line.

Example: (venv) c:\Users\dell\Desktop\evern website>

If you don't see "(venv)", try:

   venv\Scripts\activate.bat

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 5: UPGRADE PIP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python -m pip install --upgrade pip

This ensures you have the latest version of pip.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 6: INSTALL DEPENDENCIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   pip install -r requirements.txt

This will install:
   • Django 5.0+
   • Pillow (image processing)
   • django-ckeditor (text editor)
   • WhiteNoise (static files)
   • psycopg2 (PostgreSQL support)
   • And more...

Wait for installation to complete (may take 5-10 minutes depending on internet).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 7: GENERATE PROJECT STRUCTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python COMPLETE_BUILD.py

This script will:
   ✓ Create all project folders
   ✓ Generate all Django models
   ✓ Create views for each app
   ✓ Configure URLs
   ✓ Setup admin configurations
   ✓ Create all app files

Wait for it to complete.

You should see a message: "✅ PHASE 1 & 2 COMPLETE"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 8: CREATE DATABASE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python manage.py makemigrations

Then type:

   python manage.py migrate

This will:
   ✓ Create database tables
   ✓ Setup Django auth system
   ✓ Initialize all models

You should see: "Running migrations: ... OK"

A new file "db.sqlite3" will be created.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 9: CREATE ADMIN ACCOUNT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python manage.py createsuperuser

You'll be asked:

   Username: admin
   Email: admin@example.com
   Password: (enter a strong password)
   Password (again): (confirm password)

Note these credentials. You'll need them to login to admin panel.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 10: GENERATE TEMPLATES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python BUILD_TEMPLATES.py

This will create:
   ✓ All HTML templates
   ✓ CSS stylesheets
   ✓ JavaScript files
   ✓ Static assets

Wait for completion message.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 11: COLLECT STATIC FILES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python manage.py collectstatic --noinput

This organizes all CSS, JavaScript, and image files for deployment.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 12: RUN DEVELOPMENT SERVER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Type:

   python manage.py runserver

You should see:

   Starting development server at http://127.0.0.1:8000/
   Quit the server with CTRL-BREAK.

The server is now running! Don't close this command window.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 13: ACCESS YOUR WEBSITE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open your web browser and go to:

   WEBSITE:  http://localhost:8000
   ADMIN:    http://localhost:8000/admin

You should see:
   • Homepage with hero slider
   • Navigation menu
   • All sections

To login to admin:
   1. Go to http://localhost:8000/admin
   2. Enter username: admin
   3. Enter your password
   4. Click "Sign In"

🔧 USEFUL COMMANDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Press CTRL + C in command prompt

To START the server again:
   python manage.py runserver

To use different port:
   python manage.py runserver 8001

To access interactive shell:
   python manage.py shell

To backup database:
   python manage.py dumpdata > backup.json

To create new superuser:
   python manage.py createsuperuser
